# Code of Conduct

## Our standard

We want lazycaddy to be a welcoming, constructive and technically focused
project for everyone. Participants are expected to:

- be respectful and assume good intent;
- discuss ideas, code and evidence without personal attacks;
- welcome different experience levels and backgrounds;
- give actionable feedback and explain safety or compatibility concerns;
- respect the project's source-first, safety-focused design principles.

Unacceptable behavior includes harassment, discrimination, intimidation,
personal attacks, sexualized language or attention, publishing private
information, deliberate disruption, and any other conduct that would make a
reasonable participant feel unsafe or unwelcome.

## Enforcement

Please report conduct concerns privately to the repository owner through their
GitHub profile rather than opening a public issue. Reports will be reviewed in
good faith and handled as confidentially as practical.

Security vulnerabilities must follow the private process in
[SECURITY.md](SECURITY.md), not this code-of-conduct process.

Maintainers may remove or edit comments, close discussions, restrict
participation or take other reasonable action when behavior violates this
standard. Enforcement decisions should be proportionate, documented and
focused on keeping the project constructive.

This code of conduct applies to the repository, its issues, pull requests,
discussions and other project spaces maintained by the project.
